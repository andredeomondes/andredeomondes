**[JavaScript Core](https://andredeomondes.dev/series/javascript-core)** é uma série completa com 27 unidades sobre os fundamentos que tornam JavaScript previsível em um backend: tipos, funções, closures, objetos, erros, módulos, Promises, event loop, JSON, imutabilidade, legibilidade e Big O.

Cada unidade tem resumo visual, leitura, código comentado e uma prática guiada com exercícios, testes, dicas graduais e resoluções. No site dá para buscar dentro de todo o conteúdo e filtrar por série, módulo e tags.
